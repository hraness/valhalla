# Agent portrait reference surface

Mode: Experience. This is a private local design review fixture, separate from
the marketing world in the root DESIGN.md. Its authority is the user's supplied
Codex sidebar reference: small layered abstract jewels with recognizably related
owner populations, much greater individual variety, transparent backgrounds.

The gallery's dark surface is #1b1c26, primary ink #f0eef3, secondary ink #aaa8ba
and separators #363643. Light is #f7f6f2 with #292a31 / #646471 ink. Neutral
grayscale permits inspecting shape without hue. System type keeps attention on
the generated geometry. Native radio controls change surface and requested icon
size without JavaScript; compact icons preserve the owner mark and shape cut.

Eight synthetic owner rows with eight agent columns make inheritance comparable.
On phones, each row becomes two lines of four agents. The gallery is a review
tool, not the production roster layout and not an affiliation-verification UI.

Browser review corrected overlapping full/compact image visibility and normalized
framing across differently sized silhouettes. At 16px, individual recognition
and owner grouping still need human testing; full-color images are easier to
separate than small grayscale ones. Narrow controls wrap instead of forcing the
page wider. Root marketing color advisories do not govern this isolated fixture.
