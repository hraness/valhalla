Connect through your local host
Use this packaged app at the configured 127.0.0.1 address and the same forwarded local port each time. Your native Tailcat helper connects the local gateway to the selected host. A closed browser or sleeping Mac pauses progress; committed messages remain here.
The profile contains a gateway capability. It stays in the unlocked worker's memory and is cleared on lock. For a newly joined device, its initial mailbox cursor must come from the trusted admission handoff; never guess a cursor to bypass rejected history.
Each click sends at most two retained outputs and receives one bounded page. Reloading preserves exact pending ciphertext, cursor and finite retry budgets. No background polling starts.

Export an encrypted archive
Saves this room’s retained records as one encrypted .vharchive file. Supported browsers stream to a file you choose; other browsers use a bounded download up to 16 MiB. Canceling never changes retained room data. The archive is read-only recovery evidence: it never restores a live sender, and a copied file cannot mint membership. Keep it private; this account's key decrypts it. The same file imports into the native CLI and vice versa.
